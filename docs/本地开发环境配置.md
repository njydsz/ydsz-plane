## 快速启动

### 1. 使用 Docker Compose 启动基础设施

```bash
# 启动核心服务 (PostgreSQL + Redis + NATS + Mailpit)
make up

# 或者使用完整配置 (包含 ES + MinIO)
make up-full
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

`.env` 已默认配置为本地开发环境信息，可直接使用。

### 3. 执行数据库迁移 & 导入种子数据

```bash
make migrate
make seed
```

### 4. 启动后端服务

```bash
# 热重载模式 (需要 air)
make dev-api

# 或者直接运行
go run ./cmd/api
```

后端服务启动后访问: http://127.0.0.1:8080

### 5. 启动前端

```bash
cd web
pnpm install
pnpm dev
```

前端开发服务器: http://127.0.0.1:5173

## 常见问题

### Q: 连接 Redis 提示需要密码?
确认 Redis 服务已启动，且密码 `Limw1020` 正确。

### Q: 数据库迁移失败?
1. 确认 PostgreSQL 服务正常: `docker ps | grep postgres`
2. 检查连接串配置是否正确
3. 确认数据库 `ydsz` 已创建

### Q: 端口被占用?
检查端口占用情况:
```bash
netstat -ano | findstr ":8080\|:5432\|:6379\|:4222\|:5173"
```

### Q: 如何重置本地数据?
```bash
# 停止并删除所有容器和数据卷
docker compose -f deployments/docker-compose.yml down -v

# 重新启动
make up
make migrate
make seed
```
