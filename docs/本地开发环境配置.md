### Redis
- **地址**: 127.0.0.1:6379
- **密码**: Limw1020
- **用途**:
  - API 限流、会话缓存、WebSocket 扇出
  - **Outbox 事件投递（Redis Streams）**— 替代 NATS JetStream

### 事件投递：Redis Streams（替代 NATS）

原方案使用 NATS JetStream，已替换为 Redis Streams：
- **Stream Key**: `plane:events`（项目前缀，避免与共享 Redis 的其他项目冲突）
- **Consumer Group**: `plane-consumers`
- **优势**: 零额外基础设施、利用已有 Redis、运维简化

```bash
# 查看 stream 长度
XLEN plane:events

# 读取待消费事件
XINFO GROUPS plane:events
```

## 快速启动

### 1. 确认本地服务已启动

```bash
# 检查 Docker 容器状态
docker ps
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

`.env` 已默认配置为本地开发环境信息，可直接使用。

### 3. 执行数据库迁移 & 导入种子数据

```bash
make migrate
make seed
```

### 4. 启动后端服务

```bash
# 热重载模式 (需要 air)
make dev-api

# 或者直接运行
go run ./cmd/api
```

后端服务启动后访问: http://127.0.0.1:8080

### 5. 启动 Worker（事件投递）

```bash
go run ./cmd/worker
```

Worker 会自动创建 Redis Stream Consumer Group 并轮询 Outbox 事件推送至 Stream。

### 6. 启动前端

```bash
cd web
pnpm install
pnpm dev
```

前端开发服务器: http://127.0.0.1:5173

## 常见问题

### Q: 连接 Redis 失败?
本地 Redis 密码为 `Limw1020`，确认配置中 `YDSZ_REDIS_PASSWORD=Limw1020`。

### Q: 数据库迁移失败?
1. 确认 PostgreSQL 服务正常: `docker ps | grep postgre`
2. 确认数据库 `ydsz-plane` 已存在
3. 检查连接串配置是否正确

### Q: 端口被占用?
检查端口占用情况:
```bash
netstat -ano | findstr ":8080\|:5432\|:6379\|:5173"
```

### Q: 如何重置本地数据?
```bash
# 删除数据库并重新创建
docker exec -i postgre psql -U postgres -c 'DROP DATABASE "ydsz-plane";'
docker exec -i postgre psql -U postgres -c 'CREATE DATABASE "ydsz-plane";'

# 重新迁移和导入种子数据
make migrate
make seed

# 清理 Redis Stream（如有）
redis-cli -a Limw1020 DEL ydsz:events
```

### Q: Outbox 事件没有被投递?
1. 确认 Worker 进程正在运行
2. 检查 `domain_events` 表中是否有 `published_at IS NULL` 的记录
3. 查看 Redis Stream: `redis-cli -a Limw1020 XLEN ydsz:events`
