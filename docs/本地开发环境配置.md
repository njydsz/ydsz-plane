## 快速启动

### 1. 确认本地服务已启动

```bash
# 检查 Docker 容器状态
docker ps
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

`.env` 已默认配置为本地开发环境信息，可直接使用。

### 3. 执行数据库迁移 & 导入种子数据

```bash
make migrate
make seed
```

### 4. 启动后端服务

```bash
# 热重载模式 (需要 air)
make dev-api

# 或者直接运行
go run ./cmd/api
```

后端服务启动后访问: http://127.0.0.1:8080

### 5. 启动前端

```bash
cd web
pnpm install
pnpm dev
```

前端开发服务器: http://127.0.0.1:5173

## 常见问题

### Q: 连接 Redis 失败?
本地 Redis 密码为 `Limw1020`，确认配置中 `YDSZ_REDIS_PASSWORD=Limw1020`。

### Q: 数据库迁移失败?
1. 确认 PostgreSQL 服务正常: `docker ps | grep postgre`
2. 确认数据库 `ydsz-plane` 已存在
3. 检查连接串配置是否正确

### Q: 端口被占用?
检查端口占用情况:
```bash
netstat -ano | findstr ":8080\|:5432\|:6379\|:4222\|:5173"
```

### Q: 如何重置本地数据?
```bash
# 删除数据库并重新创建
docker exec -i postgre psql -U postgres -c 'DROP DATABASE "ydsz-plane";'
docker exec -i postgre psql -U postgres -c 'CREATE DATABASE "ydsz-plane";'

# 重新迁移和导入种子数据
make migrate
make seed
```
