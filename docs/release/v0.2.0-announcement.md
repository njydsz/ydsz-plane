# Ydsz Plane v0.2.0 发布公告

> 发布日期：2026-08-07
> Commit Tag：`v0.2.0`

---

## 版本主题：收口与可视化增强

v0.2 在 v0.1 稳定基础上聚焦「项目初始化模板 + 可视化视图 + 性能安全加固 + 出口文档」四大主线，打造面向中型软件团队的生产可用版本。

---

## 亮点一览

### 项目模板系统
新建项目时可选择 **敏捷 / 瀑布 / 通用** 三种预设模板，一键初始化状态流与配套工作流，落地时间从 30 分钟缩短至 30 秒。

### 三视图上线
- **甘特图**：水平时间轴 + 依赖箭头，甘特视图一目了然
- **日历视图**：月/周/日视图，按目标日期展示工作项分布
- **缺陷分析**：4 大维度交叉报表 + CSV 导出

### 性能可承载 100 万工作项
新增 7 个覆盖索引 + benchmark 采样工具 + 完整调优报告，确保 1M 工作项量级 P95 查询延迟 < 200ms。

### 安全通过等保三级基线
完成 GB/T 22239（等保三级）安全加固复查，新增 CSP/安全头/令牌桶限流，RBAC + RLS 双保险。

### 完整文档体系
用户手册、运维手册、API 参考、升级指南四本文档齐备，可独立交付客户运维团队。
