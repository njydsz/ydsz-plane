## 二、关键验证

### P0-1 自动化 DSL 设计

**Trigger 类型（12 种）**：issue.created/updated/deleted/status_changed/commented、sprint.created/started/completed、version.released/created/updated、member.added、scheduled。

**Condition 运算符（10 种）**：eq/ne/gt/gte/lt/lte/contains/in/is_empty/is_not_empty/changed。

**Action 类型（6 种）**：transition/assign/update_field/notify/create_issue/copy_field/webhook_call。

**校验门**：actions 数量 ≤10、scheduled 必须含 cron、变量引用语法校验。

### P0-2 执行器并发安全

- 同 issue 串行（Asynq 任务 key = issue_id）
- 失败熔断：连续 3 次禁用 + 告警
- 动作幂等：transition 校验当前状态、assign 校验目标用户

### P0-3 DORA 指标

| 指标 | 采集方式 | 用途 |
|------|---------|------|
| Deployment Frequency | version_released 事件计数 | 部署节奏 |
| Lead Time | issue.created → closed 时间差 | 交付周期 |
| MTTR | 缺陷 reopen → close 时间差 | 恢复时效 |
| Change Failure Rate | 缺陷数 / 版本数 | 变更质量 |
| Velocity | 近 N 迭代 story points 完成 | 团队速率 |
