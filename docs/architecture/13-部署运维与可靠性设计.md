# 13 · 部署运维与可靠性设计（全周期，S12 收口）

> 参考：Google SRE（SLO/错误预算）、12-Factor、等保三级运维要求

---

## 1. SLO 体系

| SLI | SLO | 度量 |
|-----|-----|------|
| API 可用性（非 5xx 占比） | 99.9%/30d | Prometheus http_requests_total |
| API 延迟 | P95 ≤ 200ms | histogram_quantile |
| 页面加载 | P95 ≤ 2s | 前端 web-vitals 上报 |
| 事件投递延迟（DB→worker） | P95 ≤ 5s | outbox lag |
| 搜索索引延迟 | P95 ≤ 10s | index lag |
| 通知送达 | ≥ 99.5% | send_success/total |

- 错误预算：30 天滚动；预算消耗 >50% 触发"功能冻结、优先稳定性"团队约定。
- 告警（Alertmanager）：P0 立即电话/IM（API 可用性 <99% 5min、PG 不可用、队列积压 >10k）；P1 工作时间通知（P95 超阈 30min、磁盘 >80%、证书 <14d）。

## 2. 可观测性落地

- **日志**：zap JSON；字段规范 `ts/level/msg/request_id/tenant/user/trace_id`；级别纪律（ERROR 必须可行动）；ELK 收集，保留 30 天热 + 12 个月冷。
- **指标**：RED（api 每路由）、USE（PG/Redis/ES/磁盘）、业务（注册数/需求/任务/缺陷创建率/WS 连接）；Grafana 预置 4 张面板（总览/API/依赖/业务）。
- **追踪**：OTel SDK；采样率生产 5%（错误 100%）；trace_id 注入日志与错误响应。

## 3. 备份与灾备

| 对象 | 策略 | RPO | RTO |
|------|------|-----|-----|
| PostgreSQL | 每日全量（pg_dump 或物理快照）+ WAL 持续归档；异地保留 30 天 | ≤5min | ≤1h |
| Redis | AOF；缓存可重建，不作强备份 | — | — |
| MinIO | 每日同步到第二桶/异地 | 24h | ≤4h |
| ES | 快照每日；可从 PG 重建（兜底） | 24h | ≤2h |

- 恢复演练：每季度一次"恢复到全新环境"演练并记录时长（纳入 S12 验收）。
- 备份校验：备份后自动 `pg_restore --list` 完整性检查。

## 4. 容量规划（基线规格）

| 部署形态 | 规格 | 支撑 |
|----------|------|------|
| 最小（小团队试用） | 2C4G ×1（all-in-one） | 50 用户 / 5 万需求/任务/缺陷 |
| 推荐（生产） | api 2C4G ×2 + worker 2C4G + PG 4C16G + Redis 2C4G + ES 4C8G | 1000 并发 / 100 万需求/任务/缺陷（PRD 目标） |
| 增长触发 | PG CPU>60% 持续 1 周 → 升配；ES heap>70% → 加节点 | — |

- 压测基线（k6 场景：登录/看板/详情/搜索/创建，读写 9:1）：S7 与 S12 各执行一次全量，报告归档 `docs/perf/`。

## 5. 发布与变更管理

- 发布窗口：工作日 10:00–17:00；禁周五下午发布（除 hotfix）。
- 灰度：docker 环境无网关灰度 → 采用"先 staging 验收 24h 再 prod"；K8s（Phase 3）用 canary 10%→100%。
- 回滚：镜像 tag 回退 + 迁移 expand-contract 保证 DB 向后兼容一个版本。
- 变更记录：CHANGELOG 自动生成 + Release Note 人工摘要。

## 6. 信创交付

- 构建：`GOARCH=arm64/amd64` 双架构镜像；base 提供 openEuler 22.03 / 麒麟 V10 变体。
- 数据库：达梦/人大金仓方言包（文档 04 §6）；交付前在目标库跑全量迁移 + 集成测试。
- 国密：`pkg/crypto` 双实现（x/crypto ↔ SM2/3/4），build tag `gmssl` 切换；TLS 国密由网关层（Tengine/东方通）终结。
- 浏览器兼容：360/奇安信（Chromium 内核）纳入 E2E 矩阵。

## 7. 运维手册目录（S12 交付）

`docs/ops/`：部署手册、升级指南、备份恢复 SOP、常见告警处置 Runbook（队列积压/ES 黄红/PG 慢查询/磁盘满）、oncall 轮值约定。
