### P0-3 发号器并发安全

```sql
INSERT INTO project_sequences (project_id, last_number)
VALUES ($1, 1)
ON CONFLICT (project_id) DO UPDATE
SET last_number = project_sequences.last_number + 1
RETURNING last_number;
```

利用 PG 唯一约束 + 原子 UPSERT，高并发下不产生重复 sequence_id。
