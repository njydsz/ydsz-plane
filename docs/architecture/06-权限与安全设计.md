# 06 · 权限与安全设计（S2 基线，全周期维护）

> 对应 Sprint 2（RBAC 落地）+ 全周期安全门禁
> 参考：等保三级基线（GB/T 22239）、OWASP ASVS 4.0、OWASP Top 10 2021

## 1. RBAC 模型（双层）

```
User ──< WorkspaceMember(role: owner|admin|member|guest) >── Workspace
User ──< ProjectMember(role: admin|member|viewer)        >── Project
```

**判定规则**：`effective = max(workspace_role, project_role)` 收敛为权限点集合；Guest 仅项目级查看（且需显式加入项目）；workspace owner 隐含项目 admin。

- 每个 HTTP handler 声明所需权限点（`x-permission` 注解），中间件统一鉴权，**禁止 handler 内散落 if 判断角色**。
- 资源级校验：先租户中间件限定 workspace，再按 project 成员关系过滤；非成员的 private 项目 → 404。

## 2. 认证体系

- 密码：bcrypt(cost=12)；策略 ≥8 位含字母数字；连续失败 5 次锁定 15 分钟（Redis 计数）。
- 会话：JWT access（15min，RS256）+ refresh（30d，旋转式，旧 token 重放即全家吊销）。
- CSRF：Cookie 会话强制 `X-CSRF-Token` 双重提交。
- API Token：`ydz_` 前缀，仅存 SHA-256 hash，scopes 白名单（`read:issues`、`write:issues`...），支持过期时间与 last_used_at 审计。
- 预留：TOTP 双因子（P2）、OIDC/SAML（Phase 3），认证层已抽象 `Authenticator` 接口。

## 3. 威胁模型与对策（OWASP 映射）

| 威胁 | 对策 |
|------|------|
| SQL 注入 | pgx 参数化；sqlc 生成代码；CI sql-lint 禁字符串拼接 |
| XSS | 富文本服务端消毒（bluemonday 白名单策略）；前端 `v-html` 仅用于已消毒内容；CSP `default-src 'self'` |
| CSRF | 双重提交 Token + SameSite |
| IDOR/越权 | 租户中间件 + RLS 双保险；资源校验中间件；集成测试覆盖跨租户用例 |
| 暴力破解 | 登录限流 + 锁定 + 图形/行为验证码（连续失败后） |
| 文件上传 | 类型/大小白名单（10MB 默认）；MinIO 私有桶 + 预签名（5min）；文件名重命名 UUID；图片强制转码 |
| Webhook 伪造 | HMAC-SHA256 签名 + 时间戳防重放（±5min） |
| 供应链 | 依赖锁定 + govulncheck/pnpm audit 夜扫；镜像 Trivy 扫描 |
| 日志泄露 | 脱敏中间件（password/token/email 打码）；日志禁写请求体敏感字段 |
| SSRF（Webhook/IM 回调） | 出站请求经 egress 代理，内网网段黑名单 |

## 4. 审计日志

- 范围：登录/登出、权限变更、空间/项目/成员管理、删除操作、Token 管理、Webhook/自动化配置变更、数据导出。
- 字段：`actor / action / target / detail(before→after diff) / ip / ua / request_id`。
- 保留：在线 12 个月（分区表），归档 3 年；只增不改（无 UPDATE 权限账号写入）。

## 5. 等保三级映射（基线承诺）

| 控制项 | 落地 |
|--------|------|
| 身份鉴别 | 密码策略 + 锁定 + （预留）双因子 |
| 访问控制 | RBAC + 最小权限 + 默认拒绝 |
| 安全审计 | audit_logs 全量管理操作 + 集中日志 |
| 数据完整性 | 乐观锁 + 事务 + 备份校验 |
| 数据保密性 | TLS1.2+；密码 hash；Token hash；国密构建变体（SM2/3/4，`pkg/crypto` 接口） |
| 入侵防范 | 限流、WAF 建议（部署侧）、安全头（CSP/HSTS/X-Frame-Options） |
| 备份恢复 | 每日全量 + WAL 持续归档（见文档 13） |

## 6. 前端安全

- 不存敏感信息于 localStorage（refresh token 走 HttpOnly Cookie）。
- 路由守卫 + 按钮级权限指令 `v-permission="'issue.create'`。
- 依赖 `pnpm audit` 门禁；CSP 收紧禁用 `unsafe-inline`（样式白名单 hash）。
