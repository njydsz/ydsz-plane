## 二、关键修复

### P0-1 状态机必填字段校验 Bug
- **根因**：`StateService.checkRequiredFields` 中 `toStateName` 声明后从未赋值（恒为空串），导致 `RequiredFieldsForTransition` 映射（如 `Fixed -> Verifying` 需 `root_cause_category`、`Verifying -> Closed` 需 `fix_version_id`）永远无法命中，缺陷流转的必填校验实际不生效。
- **修复**：按 `from_name -> to_name` 从 DB 查询真实状态名构造 key 匹配；`Transition()` 同时传递 `root_cause_category`/`fix_version_id` 上下文。
- **影响**：缺陷流转闭环的正确性保障（数据一致性关键修复）。
