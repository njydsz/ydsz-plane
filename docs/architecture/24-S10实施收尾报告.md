## 二、关键验证

### P0-1 Webhook 签名安全（dispatcher_test.go）

| 测试组 | 覆盖逻辑 | 结果 |
|--------|---------|------|
| TestComputeSignature | HMAC-SHA256(secret, "timestamp.body") 正确性 | ✅ |
| TestVerifySignature | hmac.Equal 时序安全比较 + 错误/空/变形签名拒绝 | ✅ 4 cases |
| TestSignatureHeader | "sha256=" 前缀格式 | ✅ |
| TestAllEvents | 事件目录非空 + 无重复 + 关键事件存在 | ✅ 16 事件 |

### P0-2 SSRF 防护基线

| 防御层 | 机制 | 位置 |
|--------|------|------|
| 协议白名单 | 仅放行 http/https | preFlightCheck |
| DNS 解析校验 | 阻止内网/保留/link-local IP | isBlockedIP |
| HTTP 客户端 | Disable redirect + TLS 1.2+ | NewDispatcher |
| 请求限制 | 1MB 响应读取上限 | deliverOne |

### P0-3 投递可靠性

- **重试**：1min / 5min / 30min 指数退避，最多 3 次
- **幂等**：唯一投递 ID（X-Ydsz-Delivery）
- **审计**：成功/失败均写 webhook_logs
- **健康状态**：连续失败标记 unhealthy
