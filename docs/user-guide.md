## 1. 产品概述

Ydsz Plane 是面向中国软件团队的开源项目管理平台，覆盖从需求/缺陷提出到迭代交付、版本发布的全生命周期。

核心能力一览：

| 能力域 | 说明 |
|--------|------|
| 工作空间与项目 | 多租户隔离、成员邀请、RBAC 权限、项目模板 |
| 工作项（Issue） | 需求 / 任务 / 缺陷三类、三级 WBS、状态机驱动、看板 + 列表 + Kanban 视图 |
| 迭代（Sprint）| 规划 → 启动 → 站会 → 复盘、燃尽图、速率统计、Backlog 拖拽 |
| 版本日（Version）| 版本聚合迭代、发布清单准出、交付报告、Release Notes |
| 全局搜索 | PostgreSQL 全文检索、历史/书签、小组件导出 |
| 通知与摘要 | 站内信、邮件、IM（企微/钉钉/飞书）、digest 日报/周报 |
| 仪表盘 | 10 种 Widget + 拖拽布局、风险告警 |
| 个人工作台 | 任务分桶、最近访问、快捷操作 |
| Webhook / Intake / 自动化 | 外部集成、公开收件、规则引擎 |

## 2. 快速上手

### 2.1 登录与首启

1. 访问 `http://localhost`（Docker Compose 部署）或 `http://localhost:5173`（本地 dev）
2. 使用种子账号登录：`admin@ydsz.dev` / `Admin@123`
3. 首次进入选择工作空间 → 进入项目列表 → 打开项目看板

### 2.2 创建工作空间

路径：左侧导航「工作空间」→「创建工作空间」

必填字段：
- 名称：空间显示名
- Slug：URL 友好标识（仅字母数字+连字符，全局唯一）
- 描述（可选）

## 3. 核心工作流

### 3.1 RBAC 角色与权限

| 角色 | 范围 | 关键权限 |
|------|------|----------|
| Owner | 全空间 | 管理空间、删除空间、转让 Ownership |
| Admin | 全空间 | 管理成员/邀请、创建项目、管理 Webhook/自动化 |
| Member | 项目内 | 创建/编辑自己工作项、评论、上传附件 |
| Guest | 项目内（指定）| 只读访问，不可编辑 |

> 默认权限矩阵详情见 [06-权限与安全设计](./architecture/06-权限与安全设计.md) §RBAC。

### 3.2 项目与工作项

#### 创建项目
工作空间 → 「新建项目」→ 选择模板（敏捷 / 瀑布 / 通用）

#### 工作项类型
- **需求（Requirement）**：大粒度业务目标
- **任务（Task）**：可执行工作单元
- **史诗（Epic）**：跨迭代的粗粒度需求集合，自动汇总子项点数
- **缺陷（Defect）**：含 severity / found_phase / root_cause / environment 等 P0 字段

#### 状态机
每个项目×类型可自定义状态流（如 待处理 → 进行中 → 已完成 → 已关闭）。
路径：项目设置 → 状态配置。

#### 看板操作
- 拖拽工作项在状态列间流转
- 双击卡片进入 Peek 预览（右侧抽屉）
- 右上角「Focus Mode」进入全屏沉浸阅读（`ESC` 退出）

#### 工作项详情
- 描述：富文本编辑器（标题/列表/代码块/Callout/任务列表/表格/图片）
- @提及同事触发站内通知
- 关联 6 种关系 / 依赖 FS/SS/FF/SF + lag_days
- 工时记录（TimeLog）
- 活动日志（按时间线）

### 3.3 迭代（Sprint）

路径：项目 → 「迭代」

1. **创建迭代**：设定起止日期、目标、容量（故事点）
2. **规划 Backlog → 迭代**：拖拽工作项入迭代
3. **启动迭代**：状态切换 active → 唯一 active 约束（同项目仅 1 个 active）
4. **站会模式**：按成员聚合昨日/今日/阻塞
5. **BurnDown 图**：实时燃尽曲线 + 理想线
6. **结束迭代**：生成复盘数据（完成率/added_midway 标记）

### 3.4 版本日（Version）

路径：项目 → 「版本」

1. 创建版本号（semver 校验：`major.minor.patch`）
2. 关联迭代
3. 状态机推进：planning → active → released → archived
4. **发布检查清单**：自定义准出条件
5. **交付报告**：聚合跨迭代进度/质量/缺陷面板
6. **Release Notes**：自定义模板自动生成

### 3.5 全局搜索

触发：顶栏搜索框或快捷键 `Cmd/Ctrl + K`

- 关键词模糊匹配（PG FTS `simple` 配置）
- 搜索历史（最近 8 条）
- 搜索书签（含共享书签）
- 类型过滤：工作项 / 迭代 / 版本 / 项目
- 导出 CSV（右上角「⬇ 导出 CSV」，最多 200 条，Excel 兼容 BOM 头）

## 4. 通知与摘要

### 4.1 站内通知
铃铛图标 → 未读计数 →「通知中心」

### 4.2 渠道与偏好
路径：空间设置 → 通知偏好

| 通道 | 说明 |
|------|------|
| In-App | 站内信（默认开启）|
| Email | SMTP 邮件（运维需配置 `YDSZ_EMAIL_*`）|
| 企业微信 / 钉钉 / 飞书 | Webhook 机器人（空间级配置）|

### 4.3 摘要（Digest）
按用户偏好聚合：realtime / daily / weekly / off
- daily 摘要：每天北京时间 08:30 投递
- weekly 摘要：每周一 08:30 投递

## 5. 仪表盘

路径：项目 → 「仪表盘」

- 拖拽布局（gridstack）
- 10 种 Widget（速率 / 燃尽 / CFD / 状态分布 / 缺陷分布 / 资源负载 / 风险告警 / DORA 四宫格 / Epic 进度 / 交付健康）
- 预设模板：敏捷 / 版本交付 / PMO
- 卡片联动过滤 + 下钻

## 6. Intake 公开收件箱

路径：空间 → 「收件箱」

- 创建通道 → 自定义字段 + Logo + 限流 + 验证码
- 公开门户：外部用户免登录提交
- 提交后获得 `tracking_id` 查询处理进度
- 内部审核 → 转为正式需求/缺陷（双向关联）

## 7. 自动化规则

路径：项目 → 「自动化」

三段式编辑器：
- **Trigger**：事件触发（工作项创建/更新/状态变更/逾期）或 cron 定时
- **Condition**：过滤条件（字段匹配 / 角色 / 优先级 等）
- **Action**：执行动作（流转 / 指派 / 通知 / 创建 / Webhook / 复制字段）

内置 7 条模板：
1. 子项全部完成 → 父项自动流转
2. 逾期自动提醒
3. 版本发布 → 关联工作项自动流转
4. Epic 故事点汇总
5. 最闲人自动指派
6. 新缺陷即时通知
7. 逾期自动开始日期标记

支持 dry-run 试运行与执行审计日志。

## 8. Webhook 集成

路径：空间 → 「Webhook」

- 订阅事件类型
- HMAC-SHA256 签名密钥（请求头 `X-Ydsz-Signature`）
- 签名格式：`sha256=<hex_hmac_sha256>`
- 投递日志保留 30 天 + 失败自动指数退避重试（1/5/30 min，≤3 次）
- 「测试推送」按钮发送 ping 事件

## 9. 附件

- 工作项描述内粘贴/拖拽上传图片
- 附件独立面板：上传 / 下载 / 预览
- 后端 MinIO（可选）或本地文件存储，预签名 URL

## 10. 个性化

- 视图偏好：列配置 / 排序 / 过滤条件 / 看板 vs 列表布局，自动持久化到 `view_preferences`
- Focus Mode：工作项详情沉浸视图（全屏阅读，`ESC` 退出）
- 工作台：自定义配置首屏 Widget

## 11. 快捷键

| 快捷键 | 动作 |
|--------|------|
| `Cmd/Ctrl + K` | 全局搜索 |
| `ESC` | 退出 Focus Mode / 关闭 Peek 抽屉 |
| `Enter`（搜索框聚焦）| 执行搜索 |
