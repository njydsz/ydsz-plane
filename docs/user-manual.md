# Ydsz Plane v0.2 — 用户手册

> 面向最终用户的操作指引，覆盖日常项目管理全部高频场景。
> 阅读时间：约 30 分钟。

---

## 1. 简介

Ydsz Plane 是面向中国软件团队的开源项目管理平台，提供工作空间管理、敏捷/瀑布工作项管理、迭代规划、版本发布、仪表盘分析、自动化 Webhook 等核心能力。

### 1.1 适用角色
| 角色 | 工作内容 |
|------|---------|
| 产品经理 | 需求编写、优先级排序、迭代规划 |
| 开发工程师 | 任务领取、进度更新、缺陷报告 |
| 测试工程师 | 缺陷提交、缺陷分析报表 |
| 项目经理/Scrum Master | 迭代管理、燃尽图、交付报告 |
| 系统管理员 | 工作空间设置、成员管理、审计 |

### 1.2 访问方式
- **Web 应用**：`https://<your-domain>/`
- **API**：`https://<your-domain>/api/v1/`

## 2. 快速上手

### 2.1 注册与登录
1. 访问 `/register`，填写邮箱 + 密码（≥ 8 位，含字母与数字）
2. 登录后默认进入工作空间列表页
3. 连续登录失败 5 次将触发 15 分钟锁定

### 2.2 创建工作空间
1. 点击「创建工作空间」
2. 填写名称、slug（URL 标识）、时区、语言
3. 创建后自动成为 owner

### 2.3 邀请成员
1. 进入「工作空间设置 → 成员」
2. 输入邮箱 + 选择角色（admin/member/guest）
3. 被邀请者邮箱收到邀请链接，点击即可加入

### 2.4 创建项目
1. 点击「创建项目」
2. 输入名称 + 选择模板（敏捷 / 瀑布 / 通用）
3. 系统自动初始化状态流（待处理 / 进行中 / 已完成 / 已取消）

## 3. 工作项管理

### 3.1 三种类型
| 类型 | 用途 | 专有字段 |
|------|------|---------|
| 需求 (requirement) | 用户故事 / 功能规格 | 来源 (customer/internal/competitor) |
| 任务 (task) | 技术任务 / 子任务 | 分类 (frontend/backend/qa/doc)、工时、延期原因 |
| 缺陷 (defect) | Bug 报告 | 严重度(1-5)、发现阶段、根因分类、验证人、环境、复现步骤 |

### 3.2 创建工作项
1. 在看板或列表视图点击「新建」
2. 选择类型、填写标题、描述（支持富文本）
3. 设置优先级（urgent / high / medium / low / none）
4. 可选：指派负责人、设置目标日期、故事点、所属模块/标签

### 3.3 状态流转
- 在看板视图拖动卡片即可触发状态流转
- 列表视图点击状态下拉框切换
- 支持的状态流转规则由管理员在「状态模板」中配置

### 3.4 视图切换
- **看板视图**：按状态列展示，支持拖拽
- **列表视图**：表格形式，支持排序 + 筛选
- **日历视图**：按目标日期分布
- **甘特图**：时间轴 + 依赖关系
- **缺陷分析**：针对缺陷的交叉分析报表

### 3.5 关联关系
支持 6 种关系：重复、相关、阻塞、开始前-前序、完成前-前序、由...实现。
在工作项详情页关联面板添加。

## 4. 迭代管理 (Sprint)

### 4.1 创建迭代
1. 进入项目 → 「迭代」列表
2. 点击「新建迭代」，填写名称、目标、起止日期
3. 设置容量（故事点数上限，可选）

### 4.2 规划 Backlog
1. 在 「规划」 视图将工作项从 Backlog 拖入 Sprint
2. 系统会校验是否超出容量限制

### 4.3 站会模式
- 迭代详情 → 「站会」 按钮进入
- 上一项 / 下一项 依次过每个进行中的工作项

### 4.4 完成迭代
- 迭代结束日期到达或手动「完成」
- 未关闭工作项自动回退至 Backlog

### 4.5 报告
- **燃尽图**：剩余故事点趋势
- **交付报告**：版本内的交付物清单

---

## 5. 版本管理

### 5.1 创建版本
- 项目 → 「版本」→「新建版本」
- 填写版本号（语义化 `vMAJOR.MINOR.PATCH`）、发布日期、计划工作项

### 5.2 发布版本
- 版本详情 → 「发布」按钮
- 自动填充发布说明（关联工作项标题拼合）
- 发布后状态锁定

### 5.3 交付报告
- 展示版本包含的所有工作项清单、工时统计、进度

---

## 6. 仪表盘

### 6.1 项目仪表盘
- 优先级分布饼图、状态分桶柱状图、逾期计数、趋势折线

### 6.2 工作台（My Workbench）
- 分配给「我」的未关闭工作项按状态分桶
- 阻塞工作项高亮

### 6.3 缺陷分析
- 严重度 / 发现阶段 / 模块 / 根因 / 缺陷龄的交叉分析
- 支持按时间范围筛选（30d / 90d / 180d / all）
- CSV 导出

---

## 7. 搜索

- 顶部全局搜索框（`Ctrl+K`）
- 支持标题 + 描述模糊匹配
- 结果按相关度排序

---

## 8. 通知

- 工作项变更、邀请、评论等事件触发通知
- 铃铛图标查看未读计数
- 通知偏好页设置订阅事件类型

---

## 9. 自动化与 Webhook (S11)

### 9.1 自动化规则
- 触发条件：工作项创建/更新/状态变更/指派
- 动作：修改字段、发送通知、调用 Webhook

### 9.2 Webhook
- 工作空间设置 → Webhook 配置
- 支持 HMAC-SHA256 签名验证
- 事件：issue.created / issue.updated / issue.deleted 等

## 10. 模板选择指南

| 模板 | 适用场景 | 初始化内容 |
|------|---------|-----------|
| 敏捷 (agile) | 敏捷/Scrum 团队 | 标准状态流 + 缺陷工作流 |

## 11. 常见问题

**Q: 如何重置密码？**
A: 登录页点击「忘记密码」，通过邮箱链接重置。

**Q: 如何迁移已存在的数据？**
A: 通过收件箱（Intake）提交工单，系统自动入库为工作项。

**Q: 支持哪些浏览器？**
A: Chrome 90+、Firefox 90+、Edge 90+（IE 不支持）。

**Q: 如何限制成员只能看到特定项目？**
A: 通过项目成员功能（admin 可见），guest 仅加入的项目可见。

**Q: 移动端能用吗？**
A: 响应式布局支持手机/平板访问，但推荐桌面端以获得最佳体验。
