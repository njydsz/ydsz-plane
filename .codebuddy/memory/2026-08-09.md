### 发现并修复的问题
1. **Go 编译失败**（两个微服务）：
   - `api/proto/search/v1/search.pb.go` 与 `notification/v1/notification.pb.go` 的 `Register*Server` 签名用了旧接口 `interface{ RegisterService(desc interface{}, impl interface{}) }`，与新版 grpc（`RegisterService(*grpc.ServiceDesc, any)`）不兼容 → 改为 `grpc.ServiceRegistrar`。
   - `cmd/notification-service/main.go`：`telemetry.NewLogger` 现需 `(level, format)`，返回 `*zap.Logger`（旧代码用 `*telemetry.Logger` 类型与单参调用）；`mq.NewEventConsumer` 不存在（改用 `mq.NewClient` + `mq.WithLogger`）；`worker.NewJitterBackoff` 不存在（改为内置指数退避）；`zap` 重复 import → 全部修正。
   - 结果：`go build ./...`、`go vet` 全绿。
2. **前端 typecheck 错误**（vue-tsc）：
   - `ImportDialog.vue`：未用导入、`typeof STEP.SELECT`、拼写 `ImportColumnMappings`、`file.value?.name`。
   - `SpreadsheetView.vue`：`updateIssue` 第4参类型 `UpdateIssueInput` 缺 `version` 且缺 `type_code/target_date/point/progress` 字段 → 用 `Record<string,unknown>` + `as unknown as UpdateIssueInput`（契约滞后于实现）。
   - `TimelineView.vue`：未用 `bounds`、ECharts `custom` series `label.formatter` 类型不兼容 → 加 `as echarts.CustomSeriesOption`。
   - `WbsTreeNode.vue`：未用 `stateColor/stateName` computed → 删除。
   - `WbsTreeView.vue`：`peek.open` 缺参（需 wsId/projectId/issueId）、`onCreated(issue)` 应为 `issueId`、`:parent-id` 传 null、缺 `:visible`、未用 `router/wsStore` → 全部修正。
3. **前端 lint**：`IssueCreateModal.vue` 真实 bug —— `parentId` 既是 prop 又是本地 ref（重复键）→ 本地 ref 重命名为 `parentIdInput`。另用 `eslint --fix` 自动修格式，3 处 `v-html` 加 `eslint-disable` 块注释（富文本渲染，内容经后端清洗）。
